# Distributed Business Platform

An international platform for creating, managing and operating independent workforce-participatory businesses.

## Project Structure

- `apps/web` — Platform web application
- `apps/api` — Backend API
- `apps/worker` — Background jobs and automation
- `packages/` — Shared application packages
- `infrastructure/` — Deployment and infrastructure configuration
- `docs/` — Architecture, policies and development documentation

## Technology

- TypeScript
- React
- Node.js
- Fastify
- PostgreSQL
- Prisma
- Docker
